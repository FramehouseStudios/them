# Archived phase prompts

The four `PHASE*_PROMPT.md` files are the historical agent prompts used to
drive the backend refactor, Postgres/auth boot, deploy, and voice-speed
phases. They are historical reference material only. The current
agent bootstrap in `AGENTS.md` does not load them, and no current script,
workflow, or documentation entry point references them. They lived at the
repository root until 2026-09-05 and were moved here so the root stays
limited to files a new contributor needs. The
[strategic audit and operating protocol](../io.them_Strategic_Audit_and_Operating_Protocol.pdf)
moved to `docs/archive/` for the same reason.
