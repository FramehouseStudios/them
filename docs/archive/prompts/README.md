# Archived phase prompts

The four `PHASE*_PROMPT.md` files are the historical agent prompts used to
drive the backend refactor, Postgres/auth boot, deploy, and voice-speed
phases. They are reference material only (AGENTS.md); nothing in the repo
links to them. They lived at the repository root until 2026-09-05 and were
moved here so the root stays limited to files a new contributor needs.
`io.them_Strategic_Audit_and_Operating_Protocol.pdf` moved to
`docs/archive/` for the same reason.
