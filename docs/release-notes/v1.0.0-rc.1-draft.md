# v1.0.0-rc.1 — draft release notes (not tagged)

Muse's 2026-09-05 audit asked for a tagged release candidate so `render.yaml`
(`autoDeploy: false`) has an artifact to promote. Tagging is a release
decision; this file is the draft that decision would ship with, prepared
from `main` on 2026-09-05. To cut it:

```sh
git tag -a v1.0.0-rc.1 -m "V1 release candidate 1 (2026-09-05)"
git push origin v1.0.0-rc.1
gh release create v1.0.0-rc.1 --prerelease --title "v1.0.0-rc.1" --notes-file docs/release-notes/v1.0.0-rc.1-draft.md
```

## Blocked on (must clear before this tag ships to TestFlight)

Each item is owned by a human; no code change can clear it.

- **Backend hosting.** `https://api.them.io` answers HTTP 302 to a domain-parking
  page as of 2026-09-06. `release_config_status.mjs` only checks the URL string;
  the default-on live backend health step in `scripts/run_release_preflight.sh`
  fails on that redirect, so the preflight cannot end `GREEN` until a backend is
  deployed at that host (or `BACKEND_URL` changes).
- **Private release values.** Real `DEVELOPMENT_TEAM_ID`, `APP_TOKEN_RELEASE`,
  and `OPENAI_API_KEY` in `them/Release.local.env` (mode 600) on the machine
  that runs the preflight, and the matching GitHub Actions secrets for the
  `rc-*` workflow.
- **LICENSE.** No license file yet; the choice is a legal decision.
- **Tag.** `v1.0.0-rc.1` is not created; cutting it is the release decision this
  draft ships with (commands above).
- **App Store privacy questionnaire.** Entries for account export/delete and
  the privacy manifest still need human confirmation in App Store Connect.
- **Manual Launch Doctor smokes.** All five pillars are `in_progress`; the
  human-run mic/playback, Studio create/save/export/reopen, memory continuity,
  realtime failover, and release sign-off smokes are still owed.
