# App Review Notes Template (macOS)

Use this as your App Review Notes in App Store Connect.

io.them is a voice conversation assistant.

Microphone usage:
- The app requests microphone access only when the user starts talking.
- Mic access is used to capture the user voice input and return spoken responses.

Data processing:
- Voice and text are processed to provide speech transcription, response generation, and text-to-speech playback.
- Conversation history and memory summaries are stored to preserve continuity across sessions.
- Users can clear conversation history and memories in the app.
